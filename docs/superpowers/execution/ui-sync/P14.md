# P14 — Login

Ported the existing login flow to a 420px dark card with scoped CSS Module, shared private auth field styling and Ant Design inputs/buttons. RHF Controller owns text field state/validation; the semantic native remember checkbox retains localStorage versus sessionStorage behavior. Existing native submit handler, single-flight guard, identity verification, validated returnTo and password visibility are unchanged. OAuth is explicitly disabled/unavailable. The scoped entrance hook cleans up on unmount and respects reduced motion; the auth canvas scrolls on short screens.

Typecheck/build through Playwright, lint and 40 auth-session/session-http unit tests passed. All 30 login/shell cases passed; after the final controller/style/entrance refinement all 11 login cases passed again. Existing cases cover USER/ADMIN, remember/reload/refresh, field focus, failed credentials, exact password preservation and explicit retry. New responsive capture covers 320 through 1600px and verifies a submit button remains reachable at 320x450. Original/runtime 390x844, 768x1024 and 1440x900 pairs reviewed. The card is taller than the source because existing remember/security explanations are retained. CSS composition was replaced with explicit scoped classes to avoid a PostCSS import warning.

Fixture/browser and UI review only; no live login/production, backend or dependency change. No push/deploy.
