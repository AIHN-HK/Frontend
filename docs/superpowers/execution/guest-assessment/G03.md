# G03 — Authentication and durable import handoff

AI/roadmap actions go through the existing login guard with an allowed internal claim return path. Signup, OTP, login and password recovery carry that intent while passwords and OTP remain memory-only. The claim page automatically imports once on a fresh authenticated handoff. It writes an owner-bound durable checkpoint before POST, defers dispatch past StrictMode setup/cleanup, aborts on leaving/account changes and discards stale acknowledgements.

Unknown outcomes retain the full guest result across reload. A guarded GET checks the durable claim; only a confirmed not-found allows an explicit idempotent POST retry. A different account cannot silently claim the pending test. Storage checkpoint failure prevents dispatch. Confirmed save clears only the matching draft, invalidates owned history/analytics and opens the chosen AI/roadmap feature.
